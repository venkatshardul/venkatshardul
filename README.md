## 🚀 Featured Projects

### 🧠 Transformer Language Model From Scratch

Exploring the architecture behind modern language models by implementing core Transformer components.

- Multi-head self-attention and causal masking.
- Understanding token embeddings and positional information.
- Experimenting with language-model training and text generation.

**Tech:** Python, PyTorch, Deep Learning

### 💹 Financial LLM Fine-Tuning

Experimenting with adapting small language models to financial question-answering tasks.

- Continued pretraining on domain-specific text.
- Supervised fine-tuning using LoRA.
- Evaluating model performance and training loss.

**Tech:** Python, PyTorch, Hugging Face, LoRA

### 🎬 Movie Recommendation System

A neural-network-based recommendation system trained on MovieLens data.

- Learns user and movie representations.
- Predicts ratings using neural networks.
- Explores embedding-based recommendation techniques.

🔗 [View Repository](https://github.com/venkatshardul/MOVIE-RECOMENDATAION-WITH-ARTIFICIALL-NEURAL-NETWORK)

**Tech:** Python, PyTorch, NumPy, MovieLens

### 🏫 Smart Attendance System

Developing an attendance application with a teacher dashboard and a face-recognition-based attendance workflow.

- Teacher authentication and subject management.
- Student photo management.
- Automated attendance prediction workflow.

**Tech:** Python, Streamlit, NumPy, Supabase

### 📈 Zerodha-Inspired Trading Platform

A project exploring the user interface and application workflows of an online trading platform.

**Focus:** Frontend development, API integration, and full-stack architecture.
